## Контрольная работа №2

## Описание

Scoofyy PC — учебный многостраничный интернет-магазин
комплектующих для компьютера.

В каталоге представлены процессор Orion X8,
видеокарта Abdula G16 Pro и оперативная память
Luchick 6 Classic Edition.

Все товары, характеристики и цены вымышлены.

## Подключение Bootstrap

Bootstrap 5.3.8 подключён через CDN на всех HTML-страницах.

Используются:

- bootstrap.min.css — стили и сетка Bootstrap;
- bootstrap.bundle.min.js — интерактивные компоненты Bootstrap.

Файл css/custom.css подключается после Bootstrap CSS
и содержит собственные изменения оформления.

Для загрузки Bootstrap через CDN требуется интернет.

## Структура проекта

- index.html — главная страница;
- catalog.html — каталог и фильтры;
- product.html — страница процессора Orion X8;
- product-abdula.html — страница видеокарты Abdula G16 Pro;
- product-luchick.html — страница памяти Luchick 6 Classic Edition;
- order.html — форма заявки;
- css/custom.css — дополнительные стили;
- js/catalog.js — фильтрация товаров;
- README.md — описание проекта;
- .gitignore — правила исключения локальных файлов из Git.

## Bootstrap-сетка

Используются container, row, адаптивные классы col-*
и классы отступов g-*.

## Bootstrap-компоненты

- navbar — навигация;
- dropdown — выпадающее меню;
- card — карточки;
- btn — кнопки;
- badge — метки товаров;
- alert — сообщения;
- modal — модальное окно проверки заявки;
- form-control — поля ввода;
- form-select — выбор товара;
- input-group — поле телефона с префиксом +7;
- form-check — чекбоксы;
- accordion — раскрывающиеся разделы о товарах;
- breadcrumb — навигационная цепочка;
- table — таблицы характеристик.

## Самостоятельные доработки

- Добавлены отдельные страницы видеокарты и оперативной памяти.

## Формы

На странице order.html размещена форма заявки.

В каталоге доступна короткая форма проверки данных
в модальном окне.

Проверка обязательных полей выполняется браузером.
Отправка данных на сервер не подключена.
Сообщения после заполнения являются демонстрационными.

## Запуск

1. Скачать или клонировать репозиторий.
2. Открыть index.html в браузере.
3. Обеспечить доступ к интернету для загрузки Bootstrap через CDN.

## Как проверить

1. Проверить переходы между страницами.
2. Применить фильтры категорий и цены в каталоге.
3. Сбросить фильтры.
4. Открыть и закрыть модальное окно.
5. Проверить обязательные поля формы заявки.
6. Раскрыть разделы Accordion на страницах товаров.
7. Проверить сайт на ширинах 375, 768, 1024 и 1440 px.

Добавлен скрипт js/last-product.js.

Скрипт сохраняет адрес последнего просмотренного товара
в localStorage браузера и обновляет ссылку «Товар» в меню.

Если история просмотра отсутствует, открывается страница
процессора Orion X8.
